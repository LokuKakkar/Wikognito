# Wikognito handbook

This set of files describes what the project is through Phase 8, what was left out on purpose, how to run a code-only copy on a new machine, how to move article backups, and what an operator still needs before a real domain.

They are meant to be copied together. The original [README.md](../README.md) is unchanged.

| File | What it covers |
|------|----------------|
| [what-is-built.md](what-is-built.md) | Product, Phases 1–7, intentional gaps |
| [new-device.md](new-device.md) | Code-only copy → running locally |
| [article-backups.md](article-backups.md) | Share and restore Wikipedia article snapshots |
| [go-live.md](go-live.md) | Checklist for a real domain |

Existing operator notes (architecture, env catalog, troubleshooting) remain under `docs/` and are optional extras.
