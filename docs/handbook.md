# Wikognito handbook

This set of files describes what the project is, what was left out on purpose, how to run a code-only copy on a new machine, and how to move article backups. The public site is already on Render.

They are meant to be copied together. Local setup lives in [DEVELOPMENT.md](../DEVELOPMENT.md). The GitHub front page is [README.md](../README.md).

| File | What it covers |
|------|----------------|
| [what-is-built.md](what-is-built.md) | Product, phases, live host, intentional gaps |
| [new-device.md](new-device.md) | Code-only copy → running locally |
| [article-backups.md](article-backups.md) | Share and restore Wikipedia article snapshots |

Existing operator notes (architecture, env catalog, troubleshooting) remain under `docs/` and are optional extras.
